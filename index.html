Your team has one game and six copies of it. Two people edited different copies. Nobody knows which one has the working jump.

No history. You can't see what changed or who changed it.

No single home. Copies live on different computers and flash drives.

No safe way to go back. Once a file is saved over, the old version is gone.

GitHub fixes all three.

Ask first (1 min): "Has this happened to you on a school project?" Take two answers, then click the button.

Git and GitHub are not the same thing

Click each one before we talk about it.

Game comparison: Git is the save-point system. GitHub is the cloud save that lets you pick up your game on another console, or let a friend play your file.
Check for understanding: "If I delete the code on my laptop, is it gone?" (No, if it's on GitHub.)

Two ways to use GitHub

Game comparison: the website is looking at your save files online. GitHub Desktop is the console that loads them, lets you play, and uploads your progress.
Say: "We'll use Desktop for our real work because our game code lives in files on these computers."

Install GitHub Desktop and sign in

Before you start

You need your GitHub username and password, and your phone if your account uses two-factor authentication.

GitHub Desktop runs on Windows 10 (64-bit) or newer, and macOS 12 or newer.

Test first: Try the install on a student login before class. School machines may block it or may wipe it at logout. If so, ask IT to deploy GitHub's .msi installer and skip step 1 and 2 with students.
